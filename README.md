# Sprint_4

Реализованные юнит-тесты для методов класса BooksCollector:
- **test_add_new_book_valid_name** - тест на добавление новой книги с валидным названием,
- **test_add_new_book_invalid_name** - тест на добавление новой книги с невалидным названием,
- **test_add_new_book_twice** - тест на добавление новой книги дважды,
- **test_set_book_genre_valid** - тест на добавление книги с валидным жанром,
- **test_set_book_genre_invalid** - тест на добавление книги с невалидным жанром,
- **test_get_books_with_specific_genre** - тест на вывод книг с определённым жанром,
- **test_get_books_genre** - тест на получение словаря books_genre,
- **test_get_books_for_children** - тест на то, что в подборку для детей попадают рарзрешенные жанры и не попадают запрещённые,
- **test_add_book_in_favorites** - тест на добавление книги в список Избранных,
- **test_delete_book_from_favorites** - тест на удаление книги из списка Избранных.
